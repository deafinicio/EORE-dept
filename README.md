# EORE dept · Твоя участь має значення

Інтерактивна презентація для знайомства молоді з відділом протимінної діяльності Харківської обласної організації Товариства Червоного Хреста України та можливостями волонтерства.

Шість екранів: знайомство, робота відділу, вибір можливої ролі, досвід, кроки до участі та запрошення до розмови. Без статистичного звіту чи непідтверджених обіцянок.

## Запуск

Статичний застосунок на HTML, CSS і JavaScript, без збірки та зовнішніх бібліотек. Усі зображення локальні. Відкрийте `index.html` або запустіть сервер:

```bash
python3 -m http.server 8080
```

Адреса: http://localhost:8080. Сервер потрібен для автоматизованих тестів. Інтернет для роботи завантаженої презентації не потрібен.

## GitHub Pages

У репозиторії вже є workflow `.github/workflows/pages.yml`. Відкрийте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Після цього запустіть **Actions → Deploy presentation → Run workflow** або зробіть наступний push у `main`.

Очікувана адреса після успішного розгортання: https://deafinicio.github.io/EORE-dept/ . README не підтверджує, що Pages уже ввімкнено.

Поки Pages вимкнено, workflow перевіряє застосунок і готує артефакт, а крок публікації пропускає. Це дозволяє пройти перевірки до ввімкнення хостингу.

## Керування

| Дія | Клавіша / елемент |
| --- | --- |
| Наступний / попередній слайд | Стрілки, Page Down / Page Up, нижні кнопки |
| Перший / останній | Home / End |
| Огляд усіх слайдів | O або «Слайди» |
| Повний екран | F або кнопка у верхній панелі, якщо підтримується браузером |
| Нотатки доповідача | N |
| Довідка | ? |
| Закрити діалог | Esc |
| Телефон | Горизонтальний свайп по вільному місцю |

Клавіші стрілок усередині вкладок «Що ми робимо» перемикають вкладки. Фокус видимий, діалоги підтримують клавіатуру, перемикання слайда оголошується допоміжним технологіям. Анімація враховує системну настройку `prefers-reduced-motion`; її також можна зменшити кнопкою. На вузькому екрані вміст прокручується вертикально.

## Інтерактивність

- Три вкладки пояснюють роботу відділу.
- Чотири напрями інтересів показують можливий внесок і приклад завдання. Обраний інтерес переходить у фінальний екран та приклад початку розмови.
- Розкривні блоки описують можливості для практики вмінь.
- Чотири кроки знайомства показують пояснення після натискання.
- Прямі посилання на екрани: `#intro`, `#purpose`, `#roles`, `#experience`, `#journey`, `#join`. Кнопки «назад» / «вперед» браузера підтримуються.
- Друк браузером формує шість сторінок, включаючи поточний вибір у динамічних блоках. Інтерактивні приховані альтернативи не є окремими сторінками.

## Контакт для онлайн-залучення

Зараз фінальний екран запрошує підійти після виступу. Кнопка «Мій перший крок» показує приклад початку розмови та дозволяє скопіювати текст. **Заявка не надсилається.** Немає вигаданого QR-коду, адреси, номера чи форми.

Щоб додати погоджену форму або офіційний контакт, змініть `site.config.js`:

```js
window.EORE_CONFIG = Object.freeze({
  contactUrl: 'https://your-approved-contact.example/',
  contactLabel: 'Зв’язатися з командою',
});
```

Використовуйте реальне погоджене HTTPS-посилання замість прикладу. Посилання з іншими протоколами приховуються. Цей застосунок не збирає персональних даних, не надсилає вибір ролі на сервер і не містить аналітичних трекерів. Вибір живе в пам’яті сторінки та скидається після перезавантаження. Зовнішнє посилання, якщо його додати, матиме власні правила обробки даних.

## Перевірка

```bash
npm ci
npx playwright install chromium
npm test
```

Тести запускають локальний сервер автоматично та перевіряють переходи, вибір ролі, вкладки з клавіатури, кроки, діалоги, історію, конфігурацію контакту, зменшення руху, мобільну версію, відсутність горизонтального переповнення й друк шести сторінок. GitHub Actions виконує перевірку перед розгортанням.

Перед показом відкрийте презентацію на комп’ютері з проєктором, увімкніть повний екран і перевірте масштаб браузера. Нотатки N відкриваються на тому самому екрані, тому аудиторія також їх бачить.
