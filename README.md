# Твоя участь має значення · EORE dept

Інтерактивна презентація для знайомства молоді з відділом протимінної діяльності Харківської обласної організації Товариства Червоного Хреста України та можливостями волонтерства.

Оформлення та принцип взаємодії адаптовано з [department-year-2026](https://github.com/deafinicio/department-year-2026), референс `88d23182bbfc515dbeb2c2ba4c4e3226d34fe97a`: темна 3D-платформа, неонове підсвічування, локальний Rubik, поступова поява об’єктів, рух камери, каталог історій, вікна деталей і кінематографічні епізоди. Код сцени адаптовано під чотири теми волонтерської презентації. Річні показники, персональні профілі й заплановану студію з річної презентації сюди не переносили.

## Шість основних кроків

1. Знайомство з відділом.
2. Що ми робимо: інформація про ризики та безпечну поведінку.
3. Твоя можлива роль: вибір близького інтересу.
4. Твій досвід: можливості застосувати й розвивати вміння.
5. Як починається участь: чотири кроки.
6. Запрошення познайомитися після виступу.

На платформі поступово з’являються чотири об’єкти. Натискання на геометрію або її HTML-підпис відкриває історію. Ті самі історії доступні кнопками й через каталог. Короткий вступ має чотири кінематографічні епізоди, фінал - два. Це режими показу тих самих матеріалів, а не додаткові основні кроки.

Зміст поки адаптовано з попередньої презентації для волонтерів і винесено у `story.js` для наступного редагування. Конкретні завдання й необхідну підготовку команда погоджує індивідуально. Наведені ролі - приклади можливого внеску.

## Запуск

Статичний застосунок без збірки та backend. Через ES modules потрібен HTTP-сервер, а не подвійне натискання на `index.html`:

```bash
python3 -m http.server 8080
```

Відкрийте http://localhost:8080 . Презентація також працює на GitHub Pages. Three.js, шрифт, фото та всі інші ресурси локальні. Для показу з локального сервера інтернет не потрібен. Без WebGL 2 доступні всі тексти, історії, вибір ролей і запрошення через HTML-кнопки; 3D та кінематографічний режим не запускаються.

## GitHub Pages

У **Settings → Pages → Build and deployment → Source** виберіть **GitHub Actions**. Після цього відкрийте **Actions → Deploy presentation → Run workflow**.

Очікувана адреса після успішної публікації: https://deafinicio.github.io/EORE-dept/ . Поки Pages вимкнено, workflow виконує перевірки та готує артефакт, а публікацію пропускає. Наступні зміни `main` перевіряються й розгортаються автоматично, якщо Pages увімкнено.

## Керування

| Дія | Клавіша / елемент |
| --- | --- |
| Наступний / попередній основний крок | ← →, Page Up / Page Down |
| Перший / останній крок | Home / End |
| Відкрити поточну історію | Enter, коли фокус на заголовку або вільному місці |
| Каталог історій | O або «Каталог історій» |
| Режим виступу, приховати допоміжні панелі | P або ▣ |
| Повний екран | F або кнопка, якщо браузер підтримує |
| Нотатки доповідача | N |
| Довідка | ? |
| Закрити історію чи епізод, вийти з режиму виступу | Esc |
| Телефон | Горизонтальний свайп по вільному місцю сцени |

В епізодах стрілки перемикають ракурси; кнопка «Відтворити» запускає автоматичну послідовність і зупиняється на останньому епізоді. Основний автопоказ переходить між кроками з інтервалом 9 секунд і зупиняється на фіналі, при взаємодії або приховуванні вкладки. Системне зменшення руху й кнопка ≈ вимикають рух камери, появу елементів та автоматичний показ. Ручні переходи залишаються доступними.

Нотатки N відкриваються на тому самому екрані, тому аудиторія також їх бачить. Режим виступу не створює окремого приватного екрана доповідача.

Друк браузером створює шість сторінок із текстом усіх тем, наявними фото й поточним обраним інтересом у фіналі. Це окрема читабельна версія для друку, без знімка WebGL-полотна.

## Структура

| Файл | Що змінювати |
| --- | --- |
| `story.js` | Тексти шести кроків, ролі, завдання, кроки участі, фото, акценти й ракурси |
| `scene.js` | 3D-платформа, геометрія об’єктів, підсвічування, поява, вибір і рух камери |
| `inspector.js` | Вкладки, вибір ролі, блоки досвіду, кроки участі, каталог і запрошення |
| `app.js` | Навігація, історія URL, автопоказ, режим виступу, доступність і відновлення без 3D |
| `cinema-story.js` | Тексти, ракурси, тривалість і кількість видимих об’єктів в епізодах |
| `cinema.js`, `cinema.css` | Керування епізодами, фокус, відтворення й оформлення |
| `styles.css` | Стиль референсу та адаптація до екранів |
| `print.js` | Шість сторінок для друку |
| `site.config.js` | Погоджене посилання на контакт або форму |
| `assets/`, `vendor/` | Локальні фото, логотип, Three.js, шрифт і ліцензії |

Прямі посилання: `#intro`, `#purpose`, `#roles`, `#experience`, `#journey`, `#join`. Кнопки браузера «назад» / «вперед» підтримуються.

## Контакт і дані

Наразі фінал запрошує підійти до команди після виступу. «Почати розмову» показує приклад звернення з обраним інтересом і дозволяє його скопіювати. **Заявка не надсилається.** Немає вигаданого контакту чи QR-коду.

Щоб додати погоджену форму або офіційний контакт, у `site.config.js` заповніть `contactUrl` реальним HTTPS-посиланням і `contactLabel` текстом кнопки. Порожнє, некоректне посилання або інший протокол приховуються. Не додавайте адресу-приклад як справжній контакт.

Обраний інтерес живе лише в пам’яті сторінки й скидається після перезавантаження. Застосунок не збирає персональних даних і не містить аналітичних трекерів. Зовнішній контакт, якщо його додати, має власні правила обробки даних.

## Перевірки

```bash
npm ci
npx playwright install --with-deps chromium
npm test
```

Дев’ять браузерних сценаріїв перевіряють реальний WebGL 2 через програмний GPU, шість кроків, raycasting і HTML-маркери, навігацію й історію, вибір ролі, інтерактивні історії, кінематографічні епізоди, ізоляцію фокусу, режим виступу, керування рухом, мобільне компонування й свайп, роботу без WebGL, перевірку контакту та друк шести сторінок. Програмний GPU дозволяє перевірити сцену в CI, але не замінює перевірку швидкодії й читабельності на реальному проєкторі.

У GitHub Actions ці самі тести використовують Chrome з [офіційного образу Ubuntu](https://github.com/actions/runner-images/blob/main/images/ubuntu/Ubuntu2404-Readme.md) через `PLAYWRIGHT_CHROMIUM_CHANNEL=chrome`. Окреме завантаження браузера та системних пакетів для CI не потрібне. Локально за замовчуванням використовується Chromium із Playwright.
